# The NYC Restroom Gap — report

*PMBA6093 · Analytics for Managers · HKU MBA group project · updated 23 September 2026*

This file used to hold a long prose report. It has been retired: it drifted out of step with
the analysis more than once. The live write-up is the site, and every number on it comes from
one generated file.

- **The site:** https://jonathanwong1990.github.io/nyc-restroom-gap/ (Walkthrough, Limits, Data & code)
- **Plain-text edition:** https://jonathanwong1990.github.io/nyc-restroom-gap/llms.txt (generated from the site)
- **Every number, with the script that produced it:** [`analysis/outputs/headline_numbers.json`](analysis/outputs/headline_numbers.json)

The project in one line: New York must plan for 2,120 public restrooms by 2035 under Local
Law 58, and its siting strategy is due on 1 Nov 2026. We answer where to put them, when they
must be open, what to do first, and how to measure the City's 17-unit modular pilot.
